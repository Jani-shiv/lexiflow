# Privacy Policy & Guarantees

## Local-Only by Design
Personal Grammar Enhancer is built strictly for zero network reliance:
1. **Zero Cloud Telemetry**: Does not send telemetry, metrics, or analytics to any server.
2. **Zero Remote APIs**: Never communicates with OpenAI, Gemini, Anthropic, Groq, or any remote AI cloud.
3. **Works Without Network**: Normal operation functions with network interfaces completely disabled.
4. **No Persistent Text Storage**: User text is held exclusively in volatile RAM within a bounded ring buffer with an automatic 30-second TTL eviction. Sentences are never written to disk or databases.
5. **Privacy-Preserving Logs**: Logging outputs structured event metrics (latency, memory usage, confidence, request IDs) and never contains user keystrokes, words, or sentences.
